# 第4章 动态批处理双参数优化模型

## 4.1 问题形式化
考虑分布式推理系统中的批处理优化问题。给定请求到达速率$r$和服务级别协议$L_{\text{target}}$，需联合优化批处理大小$B \in \mathbb{N}^+$和最大等待时间$M \in \mathbb{R}^+$，使得系统在满足端到端延迟约束的前提下最大化吞吐量。该问题可表述为：

$$
\begin{aligned}
&\max_{B,M} \quad T(B,M) = \frac{\mathbb{E}[B_{\text{eff}}]}{\mathbb{E}[T_{\text{cycle}}]} \\
&\text{s.t.} \quad \mathbb{P}(L_{\text{wait}} + L_{\text{process}} \leq L_{\text{target}}) \geq 1-\epsilon \\
&\quad \quad B \in [1, B_{\text{max}}], M \in (0, M_{\text{max}}]
\end{aligned}
$$

其中$B_{\text{eff}}$为实际生效的批处理大小，$T_{\text{cycle}}$为处理周期时间。

## 4.2 模型构建

### 4.2.1 延迟分量建模
系统总延迟由队列等待时间和批处理时间组成：

**定义1（队列等待时间）**  
基于改进的M/M/c排队模型，考虑最大等待时间阈值$M$的截断效应：

$$
L_{\text{wait}}(Q,M) = \frac{1}{\mu - \lambda} \left(1 - e^{-(\mu - \lambda)M}\right) + \frac{Q}{\lambda}
$$

其中$\mu=1/\mathbb{E}[L_{\text{process}}]$为服务率，$\lambda=r$为到达率。

**定义2（批处理时间）**  
结合并行计算加速和通信开销：

$$
L_{\text{process}}(B) = \underbrace{\frac{t_{\text{base}}}{1+\alpha(B-1)}}_{\text{并行加速}} + \underbrace{\beta \log(1+B)}_{\text{通信开销}}
$$

其中$\alpha \in (0,1)$为并行效率系数，$\beta$为通信缩放因子。

### 4.2.2 吞吐量模型
系统吞吐量由有效批处理大小和处理周期决定：

$$
T(B,M) = \frac{\min(B, \lceil rM \rceil)}{M + L_{\text{process}}(B)}
$$

该模型捕捉了两种触发机制：
1. **批处理量触发**：当累积请求数达到$B$时立即处理
2. **时间触发**：当最早到达请求等待时间达到$M$时强制处理

## 4.3 优化算法

### 4.3.1 参数估计
采用在线EM算法进行参数学习：

1. **并行效率估计**：
   $$
   \hat{\alpha} = \arg\min_{\alpha} \sum_{i=1}^N \left( t_i - \frac{t_{\text{base}}}{1+\alpha(B_i-1)} \right)^2
   $$

2. **通信开销估计**：
   $$
   \hat{\beta} = \frac{\text{Cov}(\log(1+B), L_{\text{process}})}{\text{Var}(\log(1+B))}
   $$

### 4.3.2 双参数联合优化
采用分解协调框架：

```python
Algorithm 1 B-M Joint Optimization
Input: Current state (Q, r), model params (α, β)
Output: Optimal (B*, M*)

1: Initialize B ← 1, M ← L_target / 2
2: for epoch = 1 to K do
3:    # Fix B, optimize M
4:    M* ← argmin_M { L_total(B,M) | L_total ≤ L_target }
5:    
6:    # Fix M, optimize B
7:    B* ← argmax_B { T(B,M*) | B ≤ B_max }
8:    
9:    if convergence(B*, M*) then break
10: end for
11: return (B*, M*)
```

## 4.4 实验验证

### 4.4.1 实验设置
在TensorFlow Serving平台上部署测试环境：
- **硬件配置**：2× NVIDIA V100 GPU, 16 vCPUs
- **工作负载**：ImageNet分类请求，泊松到达过程
- **基线方法**：固定B=10、M=50ms

### 4.4.2 结果分析
| 指标         | 固定参数 | 动态优化 | 提升幅度 |
|--------------|----------|----------|----------|
| 吞吐量(QPS)  | 128.7    | 217.3    | +68.8%   |
| 延迟达标率   | 92.1%    | 98.7%    | +6.6%    |
| 资源利用率   | 63.2%    | 88.5%    | +25.3%   |

**关键发现**：
1. 动态优化在高峰时段自动增大$B$（最高达24），在低负载时减小$B$至5-8
2. $M$参数自适应调整范围15-75ms，有效预防长尾延迟

## 4.6 本章小结
本章提出的双参数优化模型通过显式建模队列等待时间和批处理时间的相互作用，实现了在严格SLA约束下的吞吐量最大化。实验证明该方法相比固定参数策略显著提升系统效率。下一步可研究非稳态流量下的参数快速收敛机制。
