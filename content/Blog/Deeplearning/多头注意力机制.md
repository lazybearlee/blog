### 为何需要多头

想象一下，单头的自注意力机制就像一位**只有一个关注焦点的专家**。在分析一句话时，这位专家可能学会了关注语法结构（比如动词和主语的关系），但可能就忽略了语义上的关联（比如“苹果”和“水果”的关系）。他只能学习一种“最优”的关注模式，这限制了模型捕捉信息的能力。

**多头注意力（Multi-Head Attention）** 的核心思想，就是将这种单一的、高维度的关注过程，分解为多个并行的、低维度的关注过程。

这就像是聘请一个**专家委员会**，而不是单个专家。
*   **专家A（Head 1）** 可能专门负责捕捉句法依赖。
*   **专家B（Head 2）** 可能专门负责捕捉长距离的语义关联。
*   **专家C（Head 3）** 可能专门负责识别代词指代关系。
*   ...等等。

每个“头”（Head）都在一个独立的、更小的表示子空间（representation subspace）里学习自己的注意力模式。最后，我们将所有专家的见解（输出）汇总起来，形成一个更全面、更丰富的最终判断。

这种机制允许模型在不同位置、从不同角度同时关注信息，极大地增强了模型的表达能力。

### 多头注意力的形式化解析

现在，我们把这个“专家委员会”的比喻，转化为精确的数学和工程步骤。我们将整个过程分解。

假设：
*   输入张量形状为 `(batch_size, seq_len, d_model)`
*   我们设定头的数量为 `h` (e.g., 8)
*   因此，每个头的维度 `d_head` 就是 `d_model / h`。这个关系至关重要，它意味着我们并没有增加总的计算量，而是将原有的计算“重塑”了。

#### 第一步 初始线性投射

这一步和单头注意力完全相同。我们首先通过三个独立的线性层，为整个模型（所有头共享）生成初始的查询（Q）、键（K）和值（V）矩阵。

*   $Q = XW_Q$
*   $K = XW_K$
*   $V = XW_V$

$W_Q, W_K, W_V$ 是可学习的权重矩阵，它们的尺寸都是 `(d_model, d_model)`。因此，$Q, K, V$ 的形状仍然是 `(batch_size, seq_len, d_model)`。

#### 第二步 分割为多头

这是多头机制的核心技巧。我们现在需要将 `d_model` 维度的 $Q, K, V$ 向量，分割成 `h` 个 `d_head` 维度的向量。

在实现上，这通常通过一个巧妙的 `reshape` 和 `transpose` 操作完成：
1.  **Reshape**: 将形状为 `(batch_size, seq_len, d_model)` 的张量重塑为 `(batch_size, seq_len, h, d_head)`。我们把 `d_model` 这个维度“掰开”成了 `h` 和 `d_head` 两个维度。
2.  **Transpose**: 为了让每个头能够独立进行矩阵乘法，我们需要将 `h` 这个维度提到前面。所以，我们将张量转置为 `(batch_size, h, seq_len, d_head)`。

现在，我们得到了 `h` 组独立的 $Q_i, K_i, V_i$（其中 $i$ 从 1 到 $h$），每一组的维度都是 `d_head`。

#### 第三步 并行计算注意力

现在，我们让 `h` 个头（专家）并行地、独立地执行标准的**缩放点积注意力**。

对于每一个头 $i$：

$$
\text{head}_i = \text{Attention}(Q_i, K_i, V_i) = \text{softmax}\left(\frac{Q_i K_i^T}{\sqrt{d_k}}\right)V_i
$$

注意，这里的 $d_k$ 就是每个头的维度 `d_head`。

因为我们已经将张量整理成了 `(batch_size, h, seq_len, d_head)` 的形状，这个并行的计算可以在一个高效的批处理矩阵乘法（`bmm`）中完成。计算的结果，即所有头的输出 `head_1, ..., head_h`，被整合在一个形状同样为 `(batch_size, h, seq_len, d_head)` 的张量中。

#### 第四步 拼接与最终投射

专家们给出了各自的意见，现在需要一位“主席”来整合这些意见，形成最终决议。

1.  **拼接（Concatenate）**: 这个操作是第二步“分割”的逆过程。我们将 `h` 个头的输出拼接回一个单一的张量。
    *   **Transpose**: `(batch_size, h, seq_len, d_head)` -> `(batch_size, seq_len, h, d_head)`
    *   **Reshape**: `(batch_size, seq_len, h, d_head)` -> `(batch_size, seq_len, d_model)`

    经过这一步，我们得到了一个形状为 `(batch_size, seq_len, d_model)` 的张量，它包含了所有头的注意力信息。

2.  **最终线性投射**: 最后，我们将这个拼接后的张量通过另一个线性层 $W_O$（权重矩阵大小为 `(d_model, d_model)`），进行最后的信息融合和转换。

    $$
    \text{MultiHeadOutput} = \text{Concat}(\text{head}_1, \dots, \text{head}_h)W_O
    $$

这个最终的输出张量，其形状为 `(batch_size, seq_len, d_model)`，可以被送入 Transformer 的下一层（比如前馈网络）。

### PyTorch 代码实现

```python
import torch
import torch.nn as nn
import math

def scaled_dot_product_attention(q, k, v, mask=None):
    """
    独立的缩放点积注意力函数。
    q, k, v 的形状: (batch_size, num_heads, seq_len, d_head)
    """
    d_head = q.size(-1)
    # 矩阵乘法: (..., seq_len, d_head) @ (..., d_head, seq_len) -> (..., seq_len, seq_len)
    scores = torch.matmul(q, k.transpose(-2, -1)) / math.sqrt(d_head)
    
    if mask is not None:
        # mask的形状通常是 (batch_size, 1, 1, seq_len) 或 (batch_size, 1, seq_len, seq_len)
        scores = scores.masked_fill(mask == 0, float('-inf'))
        
    attention_weights = torch.softmax(scores, dim=-1)
    output = torch.matmul(attention_weights, v)
    return output, attention_weights


class MultiHeadAttention(nn.Module):
    def __init__(self, d_model: int, h: int):
        """
        初始化多头注意力模块
        d_model: 模型的总维度
        h: 头（Head）的数量
        """
        super().__init__()
        # 确保d_model可以被h整除
        assert d_model % h == 0, "d_model must be divisible by h"
        
        self.d_model = d_model
        self.h = h
        self.d_head = d_model // h
        
        # 第一步: 定义初始线性投射层
        self.query_proj = nn.Linear(d_model, d_model)
        self.key_proj = nn.Linear(d_model, d_model)
        self.value_proj = nn.Linear(d_model, d_model)
        
        # 第四步: 定义最终的线性投射层
        self.final_proj = nn.Linear(d_model, d_model)

    def forward(self, x: torch.Tensor, mask: torch.Tensor = None):
        # x 的输入形状: (batch_size, seq_len, d_model)
        batch_size, seq_len, _ = x.shape

        # 第一步: 初始线性投射
        # (batch, seq_len, d_model) -> (batch, seq_len, d_model)
        q = self.query_proj(x)
        k = self.key_proj(x)
        v = self.value_proj(x)
        
        # 第二步: 分割为多头
        # view 操作将 d_model 维度拆分为 h 和 d_head
        # (batch, seq_len, d_model) -> (batch, seq_len, h, d_head)
        # transpose 操作将 h 维度提前，方便并行计算
        # (batch, seq_len, h, d_head) -> (batch, h, seq_len, d_head)
        q = q.view(batch_size, seq_len, self.h, self.d_head).transpose(1, 2)
        k = k.view(batch_size, seq_len, self.h, self.d_head).transpose(1, 2)
        v = v.view(batch_size, seq_len, self.h, self.d_head).transpose(1, 2)

        # 第三步: 并行计算注意力
        # scaled_dot_product_attention在 (batch, h, seq_len, d_head) 上操作
        # 输出 attention_output 的形状也是 (batch, h, seq_len, d_head)
        attention_output, _ = scaled_dot_product_attention(q, k, v, mask)
        
        # 第四步: 拼接与最终投射
        # transpose 和 contiguous().view() 是第二步的逆操作
        # (batch, h, seq_len, d_head) -> (batch, seq_len, h, d_head)
        concatenated_output = attention_output.transpose(1, 2).contiguous()
        # (batch, seq_len, h, d_head) -> (batch, seq_len, d_model)
        concatenated_output = concatenated_output.view(batch_size, seq_len, self.d_model)
        
        # (batch, seq_len, d_model) -> (batch, seq_len, d_model)
        final_output = self.final_proj(concatenated_output)
        
        return final_output

# --- 使用示例 ---
# 参数设定
d_model_example = 512 # BERT-base 的隐藏维度
h_example = 8         # BERT-base 的头数
seq_len_example = 10  # 序列长度
batch_size_example = 4 # 批次大小

# 实例化模型
mha_layer = MultiHeadAttention(d_model=d_model_example, h=h_example)

# 创建一个随机输入张量
input_tensor = torch.randn(batch_size_example, seq_len_example, d_model_example)

# 前向传播
output_tensor = mha_layer(input_tensor)

print("--- 输入张量形状 ---")
print(input_tensor.shape)
print("\n--- 输出张量形状 ---")
print(output_tensor.shape)
print(f"\n每个头的维度 (d_head): {d_model_example} / {h_example} = {mha_layer.d_head}")
```
