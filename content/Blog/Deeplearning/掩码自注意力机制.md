### 为何需要掩码

在标准的自注意力机制中，序列中的每一个位置（Token）在计算其新表示时，都会与序列中**所有**其他位置进行交互。这在处理非序列性任务（如文本分类）时非常有效，因为它能捕捉全局依赖关系。

然而，在生成式任务中，模型必须是**自回归（Autoregressive）** 的。这意味着在预测第 $t$ 个位置的输出时，模型**只能**依赖于第 $1, 2, \dots, t-1$ 位置的输入，绝不能看到任何未来的信息（即 $t, t+1, \dots$ 位置）。==如果模型在训练时能够看到未来的答案，它就会学走一条“捷径”，直接复制未来的输入作为预测，而无法学到真正的序列生成能力。==

**掩码自注意力机制**的核心使命，就是在保持自注意力强大表示能力的同时，强制施加这种“只能看过去”的因果（Causal）约束。

### 自注意力机制回顾

在深入掩码之前，我们先回顾一下标准的缩放点积注意力（Scaled Dot-Product Attention）的计算过程。这是所有注意力的基础。

输入是三个矩阵：查询（Query, $Q$）、键（Key, $K$）和值（Value, $V$）。它们由同一个输入序列通过不同的线性变换得到。其核心公式为：

$$
\text{Attention}(Q, K, V) = \text{softmax}\left(\frac{QK^T}{\sqrt{d_k}}\right)V
$$

其中，$d_k$ 是键向量的维度。这个公式描述了以下过程：
1.  **计算相似度分数**：通过 $Q$ 和 $K$ 的点积 $QK^T$ 来计算每个查询与所有键之间的原始相似度。
2.  **缩放**：将分数除以 $\sqrt{d_k}$ 进行缩放，以防止梯度过小。
3.  **归一化**：应用 `softmax` 函数将分数转换为概率分布，即注意力权重。
4.  **加权求和**：用得到的注意力权重对 $V$ 进行加权求和，得到最终的输出。

现在，我们的任务就是在这个流程中，植入“防止看到未来”的约束。

### 掩码自注意力机制的形式化解析

我们将这个过程分解为一系列精确的步骤，并观察张量形状的变化。假设我们的输入序列长度为 `seq_len`，批次大小为 `batch_size`，模型的隐藏维度为 `d_model`。

#### 第一步 输入与线性投射

输入是一个形状为 `(batch_size, seq_len, d_model)` 的张量。我们通过三个独立的线性层，将其投射到 $Q, K, V$。

*   $Q = XW_Q$
*   $K = XW_K$
*   $V = XW_V$

$W_Q, W_K, W_V$ 是可学习的权重矩阵。投射后，$Q, K, V$ 的形状仍然是 `(batch_size, seq_len, d_model)`（在多头注意力中，这个维度会被切分，但我们暂时简化为单头来理解核心逻辑）。

#### 第二步 计算原始注意力分数

我们计算查询和键的点积，得到注意力分数矩阵。

$$
\text{Scores} = QK^T
$$

*   $Q$ 的形状: `(batch_size, seq_len, d_model)`
*   $K^T$ (K转置) 的形状: `(batch_size, d_model, seq_len)`
*   `Scores` 的形状: `(batch_size, seq_len, seq_len)`

这个 `Scores` 矩阵的物理意义是：`Scores[b, i, j]` 代表了在批次 `b` 中，第 `i` 个位置的查询对第 `j` 个位置的键的原始关注程度。此时，每个位置 `i` 都关注了包括自己在内的所有位置 `j`。

#### 第三步 创建与应用因果掩码

这是整个机制的关键。我们需要创建一个掩码（Mask），它能够“遮盖”掉所有未来的信息。

1.  **创建掩码矩阵**：我们构建一个形状为 `(seq_len, seq_len)` 的矩阵，我们称之为 `Mask`。这个矩阵的上三角部分（不包括对角线）填充为一个非常大的负数（通常是负无穷，`−∞`），而下三角部分（包括对角线）填充为 `0`。

    $$
    \text{Mask} =
    \begin{pmatrix}
    0 & -\infty & -\infty & \dots & -\infty \\
    0 & 0 & -\infty & \dots & -\infty \\
    0 & 0 & 0 & \dots & -\infty \\
    \vdots & \vdots & \vdots & \ddots & \vdots \\
    0 & 0 & 0 & \dots & 0
    \end{pmatrix}
    $$

2.  **应用掩码**：我们将这个 `Mask` 矩阵**加到** `Scores` 矩阵上。

    $$
    \text{Scores}_{\text{masked}} = \text{Scores} + \text{Mask}
    $$

    我们来分析一下这个加法操作的效果：
    *   对于下三角部分（`j <= i`），`Scores[b, i, j]` 加上 `0`，其值保持不变。这表示一个位置 `i` 可以关注它自己以及它之前的所有位置 `j`。
    *   对于上三角部分（`j > i`），`Scores[b, i, j]` 加上 `−∞`，其值变为 `−∞`。这表示一个位置 `i` **不能**关注它之后任何位置 `j` 的信息。

#### 第四步 缩放与 Softmax

接下来，我们照常进行缩放和 `softmax` 操作。

$$
\text{AttentionWeights} = \text{softmax}\left(\frac{\text{Scores}_{\text{masked}}}{\sqrt{d_k}}\right)
$$

`softmax` 函数的定义是 $e^{z_i} / \sum_j e^{z_j}$。当一个元素 $z_j$ 是 `−∞` 时，它的指数 $e^{-\infty}$ 会趋近于 `0`。因此，经过 `softmax` 之后：

*   那些被掩码（值为 `−∞`）的位置，其对应的注意力权重会**精确地变为 `0`**。
*   那些未被掩码的位置，其权重会被重新归一化，使得它们的和为 `1`。

最终得到的 `AttentionWeights` 矩阵，其上三角部分将全是零，完美地实现了因果约束。

#### 第五步 加权求和

最后一步和标准注意力完全相同，用计算出的注意力权重对 `Value` 矩阵进行加权求和。

$$
\text{Output} = \text{AttentionWeights} \cdot V
$$

*   `AttentionWeights` 的形状: `(batch_size, seq_len, seq_len)`
*   `V` 的形状: `(batch_size, seq_len, d_model)`
*   `Output` 的形状: `(batch_size, seq_len, d_model)`

由于权重矩阵的上三角部分为零，在计算第 `i` 个位置的输出时，所有来自未来位置（`j > i`）的 `Value` 向量 `V[:, j, :]` 的贡献都将是零，因为它们乘以了零权重。

至此，我们从数学上完整地实现了掩码自注意力。

### PyTorch 代码实现

```python
import torch
import torch.nn as nn
import math

class MaskedSelfAttention(nn.Module):
    """
    一个实现了掩码自注意力（单头）的PyTorch模块。
    这旨在教学和清晰地展示其内部工作原理。
    """
    def __init__(self, d_model: int):
        super().__init__()
        if d_model % 1 != 0: # 简化，假设d_model能被头数整除
            raise ValueError("d_model必须是整数")
            
        self.d_model = d_model
        
        # 定义Q, K, V的线性投射层
        # 在实际Transformer中，这通常是一个大的线性层然后切分
        self.query_proj = nn.Linear(d_model, d_model)
        self.key_proj = nn.Linear(d_model, d_model)
        self.value_proj = nn.Linear(d_model, d_model)
        
        self.softmax = nn.Softmax(dim=-1) # 在最后一个维度上进行softmax

    def forward(self, x: torch.Tensor):
        # x: 输入张量，形状为 (batch_size, seq_len, d_model)
        batch_size, seq_len, d_model = x.shape

        # 第一步: 输入与线性投射
        # (batch_size, seq_len, d_model) -> (batch_size, seq_len, d_model)
        q = self.query_proj(x)
        k = self.key_proj(x)
        v = self.value_proj(x)

        # 第二步: 计算原始注意力分数
        # (batch, seq_len, d_model) @ (batch, d_model, seq_len) -> (batch, seq_len, seq_len)
        scores = torch.bmm(q, k.transpose(1, 2))

        # 第三步: 创建与应用因果掩码
        # 1. 创建一个上三角矩阵，对角线以上为1，其他为0
        mask = torch.triu(torch.ones(seq_len, seq_len), diagonal=1).bool()
        mask = mask.to(x.device) # 确保掩码和输入在同一设备上
        
        # 2. 应用掩码: 将mask中为True的位置（未来的位置）的值替换为一个非常大的负数
        # masked_fill_ 是一个in-place操作
        scores.masked_fill_(mask, float('-inf'))
        
        # 第四步: 缩放与Softmax
        # 缩放因子
        scale_factor = math.sqrt(self.d_model)
        # (batch, seq_len, seq_len) -> (batch, seq_len, seq_len)
        attention_weights = self.softmax(scores / scale_factor)

        # 第五步: 加权求和
        # (batch, seq_len, seq_len) @ (batch, seq_len, d_model) -> (batch, seq_len, d_model)
        output = torch.bmm(attention_weights, v)
        
        # 返回最终输出和注意力权重（用于可视化和调试）
        return output, attention_weights


# --- 使用示例 ---
# 参数设定
d_model_example = 16  # 模型的隐藏维度
seq_len_example = 5   # 序列长度
batch_size_example = 1 # 批次大小

# 实例化模型
masked_attention_layer = MaskedSelfAttention(d_model=d_model_example)

# 创建一个随机输入张量
input_tensor = torch.randn(batch_size_example, seq_len_example, d_model_example)

# 前向传播
output_tensor, weights = masked_attention_layer(input_tensor)

print("--- 输入张量形状 ---")
print(input_tensor.shape)
print("\n--- 输出张量形状 ---")
print(output_tensor.shape)
print("\n--- 注意力权重矩阵 (Attention Weights) ---")
# 我们只看第一个批次的结果
print(weights.squeeze(0).detach().round(decimals=4))
```

```
--- 注意力权重矩阵 (Attention Weights) ---

        [0.4578, 0.5422, 0.0000, 0.0000, 0.0000],

        [0.1982, 0.2016, 0.2059, 0.1965, 0.1978]])
```

请仔细观察这个**注意力权重矩阵**：
*   **第一行**：第一个位置只能关注自己，所以它的权重 `[1.0000, 0.0000, 0.0000, 0.0000, 0.0000]` 全部分配给了第一个位置。
*   **第二行**：第二个位置可以关注第一个和第二个位置，权重在它们之间分配，而对第3、4、5个位置的权重都是 `0`。
*   **后续行**：以此类推，每一行 `i` 的权重只分布在 `0` 到 `i` 列上，`i` 列之后的所有权重都为零。
