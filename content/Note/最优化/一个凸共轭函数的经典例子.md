## 1. 预备知识：凸共轭函数的定义

设 $f: \mathbb{R}^n \to \overline{\mathbb{R}}$ 是一个凸函数。它的共轭函数 $f^*: \mathbb{R}^n \to \overline{\mathbb{R}}$ 定义为：

$$f^*(\mathbf{y}) \triangleq \sup_{\mathbf{x} \in \mathbb{R}^n} \left( \mathbf{y}^T \mathbf{x} - f(\mathbf{x}) \right)$$

这个运算是 **Legendre-Fenchel 变换**。共轭函数 $f^*(\mathbf{y})$ 几何上可以理解为 $f(\mathbf{x})$ 的所有支撑超平面的截距的负值。

---

## 2. 问题分析与推导

考虑二次函数 $f(\mathbf{x})$：
$$f(\mathbf{x}) = \frac{1}{2}\mathbf{x}^T A\mathbf{x} + \mathbf{b}^T \mathbf{x} + c$$
其中 $A \in \mathcal{S}^n$（对称矩阵），且 $A \succeq 0$（保证 $f$ 是凸函数）。

我们需要求解 $\mathbf{y}^T \mathbf{x} - f(\mathbf{x})$ 的上确界：
$$f^*(\mathbf{y}) = \sup_{\mathbf{x}} \left( \mathbf{y}^T \mathbf{x} - \left( \frac{1}{2}\mathbf{x}^T A\mathbf{x} + \mathbf{b}^T \mathbf{x} + c \right) \right)$$
$$f^*(\mathbf{y}) = \sup_{\mathbf{x}} \left( (\mathbf{y} - \mathbf{b})^T \mathbf{x} - \frac{1}{2}\mathbf{x}^T A\mathbf{x} - c \right)$$

设 $h(\mathbf{x}) = (\mathbf{y} - \mathbf{b})^T \mathbf{x} - \frac{1}{2}\mathbf{x}^T A\mathbf{x} - c$。这是一个关于 $\mathbf{x}$ 的**凹函数**（因为 $-\frac{1}{2}\mathbf{x}^T A\mathbf{x}$ 是凹的）。求其上确界等价于求其极大值。

### 2.1 案例 (1): 强凸情形 ($A \succ 0$)

当 $A$ 是正定矩阵时 ($A \succ 0$)，它可逆，且 $h(\mathbf{x})$ 是严格凹函数，因此存在唯一的极值点 $\mathbf{x}^*$。

**求解 $\mathbf{x}^*$：**
我们对 $h(\mathbf{x})$ 求梯度并令其为零（一阶最优性条件）：
$$\nabla_{\mathbf{x}} h(\mathbf{x}) = (\mathbf{y} - \mathbf{b}) - A\mathbf{x} = \mathbf{0}$$
$$\implies A\mathbf{x}^* = \mathbf{y} - \mathbf{b}$$
由于 $A$ 可逆，我们得到唯一的极值点：
$$\mathbf{x}^* = A^{-1} (\mathbf{y} - \mathbf{b})$$

**代入求 $f^*(\mathbf{y})$：**
将 $\mathbf{x}^*$ 代回 $h(\mathbf{x})$ 的表达式：
$$\begin{aligned} f^*(\mathbf{y}) &= h(\mathbf{x}^*) \\ &= (\mathbf{y} - \mathbf{b})^T \mathbf{x}^* - \frac{1}{2}(\mathbf{x}^*)^T A\mathbf{x}^* - c \end{aligned}$$

利用 $A\mathbf{x}^* = \mathbf{y} - \mathbf{b}$：
$$\begin{aligned} f^*(\mathbf{y}) &= (A\mathbf{x}^*)^T \mathbf{x}^* - \frac{1}{2}(\mathbf{x}^*)^T A\mathbf{x}^* - c \\ &= (\mathbf{x}^*)^T A^T \mathbf{x}^* - \frac{1}{2}(\mathbf{x}^*)^T A\mathbf{x}^* - c \end{aligned}$$
由于 $A$ 是对称矩阵 ($A^T = A$)：
$$f^*(\mathbf{y}) = (\mathbf{x}^*)^T A\mathbf{x}^* - \frac{1}{2}(\mathbf{x}^*)^T A\mathbf{x}^* - c = \frac{1}{2}(\mathbf{x}^*)^T A\mathbf{x}^* - c$$

最后，将 $\mathbf{x}^* = A^{-1} (\mathbf{y} - \mathbf{b})$ 代入上式：
$$f^*(\mathbf{y}) = \frac{1}{2} \left( A^{-1} (\mathbf{y} - \mathbf{b}) \right)^T A \left( A^{-1} (\mathbf{y} - \mathbf{b}) \right) - c$$
$$f^*(\mathbf{y}) = \frac{1}{2} (\mathbf{y} - \mathbf{b})^T (A^{-1})^T A A^{-1} (\mathbf{y} - \mathbf{b}) - c$$
由于 $A^{-1}$ 是对称的， $(A^{-1})^T = A^{-1}$，且 $A A^{-1} = I$：
$$f^*(\mathbf{y}) = \frac{1}{2} (\mathbf{y} - \mathbf{b})^T A^{-1} (\mathbf{y} - \mathbf{b}) - c$$

---

### 2.2 案例 (2): 一般凸情形 ($A \succeq 0$)

当 $A$ 只是半正定 ($A \succeq 0$) 时， $A$ 不可逆，所以我们不能直接使用 $A^{-1}$。我们必须考虑 $h(\mathbf{x})$ 的最大值何时存在。

**最大值存在性：**
最大值存在，当且仅当梯度为零的条件 $A\mathbf{x} = \mathbf{y} - \mathbf{b}$ 有解。

根据线性代数知识，方程 $A\mathbf{x} = \mathbf{v}$ 有解，当且仅当 $\mathbf{v}$ 位于 $A$ 的像空间（列空间）$\mathcal{R}(A)$ 中。
因此， $h(\mathbf{x})$ 的最大值存在，当且仅当：
$$\mathbf{y} - \mathbf{b} \in \mathcal{R}(A)$$
这定义了 $f^*(\mathbf{y})$ 的定义域 $\text{dom} f^*$:
$$\text{dom} f^* = \{ \mathbf{y} \mid \mathbf{y} - \mathbf{b} \in \mathcal{R}(A) \} = \mathcal{R}(A) + \mathbf{b}$$

**求解 $\mathbf{x}^*$ 和 $f^*(\mathbf{y})$：**
由于 $A$ 不可逆，我们使用**伪逆矩阵 $A^{\dagger}$** 来找到梯度方程 $A\mathbf{x} = \mathbf{y} - \mathbf{b}$ 的最小二乘解或最小范数解。最小范数解是：
$$\mathbf{x}^* = A^{\dagger} (\mathbf{y} - \mathbf{b})$$

注意：对于半正定二次函数，我们不需要担心哪个解被选中，因为所有满足 $A\mathbf{x} = \mathbf{y} - \mathbf{b}$ 的 $\mathbf{x}$ 都会产生相同的极大值 $f^*(\mathbf{y})$。

我们将 $\mathbf{x}^*$ 代入简化后的极大值表达式 $\frac{1}{2}(\mathbf{x}^*)^T A\mathbf{x}^* - c$：
$$f^*(\mathbf{y}) = \frac{1}{2} (\mathbf{y} - \mathbf{b})^T (A^{\dagger})^T A A^{\dagger} (\mathbf{y} - \mathbf{b}) - c$$

对于对称矩阵 $A$，其伪逆 $A^{\dagger}$ 也是对称的 $((A^{\dagger})^T = A^{\dagger})$。
此外，对于任何对称矩阵 $A$， $A A^{\dagger} A = A$ 和 $A^{\dagger} A A^{\dagger} = A^{\dagger}$。
关键性质：**$A A^{\dagger}$ 是到 $\mathcal{R}(A)$ 的正交投影矩阵。**

当 $\mathbf{y} - \mathbf{b} \in \mathcal{R}(A)$ 时，投影矩阵 $P = A A^{\dagger}$ 作用在 $\mathbf{y} - \mathbf{b}$ 上等于它自身：
$$A A^{\dagger} (\mathbf{y} - \mathbf{b}) = \mathbf{y} - \mathbf{b}$$

我们利用 $A^{\dagger} A A^{\dagger} = A^{\dagger}$:
$$(A^{\dagger})^T A A^{\dagger} = A^{\dagger} A A^{\dagger} = A^{\dagger}$$

将此代入 $f^*(\mathbf{y})$ 的表达式：
$$f^*(\mathbf{y}) = \frac{1}{2} (\mathbf{y} - \mathbf{b})^T A^{\dagger} (\mathbf{y} - \mathbf{b}) - c$$

## 3. 结论和几何意义

**凸共轭函数的性质：**

无论 $f$ 是否严格凸，其共轭函数 $f^*$ 总是凸函数。

| 特性 | $f(\mathbf{x})$ (原始函数) | $f^*(\mathbf{y})$ (共轭函数) |
| :--- | :--- | :--- |
| **函数形式** | $\frac{1}{2}\mathbf{x}^T A\mathbf{x} + \mathbf{b}^T \mathbf{x} + c$ | $\frac{1}{2}(\mathbf{y} - \mathbf{b})^T A^{\dagger} (\mathbf{y} - \mathbf{b}) - c$ |
| **凸性要求** | $A \succeq 0$ (半正定) | 总是凸的 |
| **严格凸性** | $A \succ 0$ (强凸) | $A^{\dagger} \succ 0$ (强凸) |
| **共轭定义域**| $\mathbb{R}^n$ | $\mathcal{R}(A) + \mathbf{b}$ |

这个结果体现了对偶理论的对称性：原始函数是二次函数，其共轭函数也是二次函数。强凸性（$A \succ 0$）保证了原函数在所有方向上都具有二次增长，从而共轭函数定义在整个空间 $\mathbb{R}^n$ 上。一般凸性（$A \succeq 0$）则限制了共轭函数的定义域，使其只能在 $\mathcal{R}(A) + \mathbf{b}$ 这一仿射子空间上取有限值。
