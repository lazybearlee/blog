## 思路分析

损失函数设计包含两个关键部分：

1. **点击样本处理**：
   - 当下一个token是点击样本时，计算对比损失
   - 使用两种负样本：
     - 局部负样本：当前序列中曝光但未点击的物品
     - 全局负样本：全局未曝光物品
1. **曝光未点击样本处理**：
   - 当下一个token是曝光未点击样本时，降低其点击率预测结果
   - 这相当于给模型一个明确的负信号

这种设计有几个优势：
- 充分利用曝光序列中的所有信息
- 局部负样本更具有挑战性（因为它们已经被系统推荐给用户）
- 全局负样本保证多样性
- 明确区分点击和曝光未点击的行为

        super().__init__()
        self.data_dir = Path(data_dir)

            self.itemnum = len(indexer['i'])
            self.usernum = len(indexer['u'])
        
        # 构建反向索引
        self.indexer_i_rev = {v: k for k, v in indexer['i'].items()}
        self.indexer_u_rev = {v: k for k, v in indexer['u'].items()}
        self.indexer = indexer
        
        # 初始化特征信息
        self.feature_default_value, self.feature_types, self.feat_statistics = self._init_feat_info()
        
        # 新增：负采样参数
        self.num_local_neg = args.num_local_neg if hasattr(args, 'num_local_neg') else 3
        self.num_global_neg = args.num_global_neg if hasattr(args, 'num_global_neg') else 2

    def __getitem__(self, uid):
        user_sequence = self._load_user_data(uid)
        
        ext_user_sequence = []
        # 收集用户曝光但未点击的物品（用于局部负采样）
        exposed_not_clicked = set()
        # 收集用户点击的物品（用于冲突检测）
        clicked_items = set()
        
        for record_tuple in user_sequence:
            u, i, user_feat, item_feat, action_type, _ = record_tuple
            if u and user_feat:
                ext_user_sequence.insert(0, (u, user_feat, 2, action_type))
            if i and item_feat:
                ext_user_sequence.append((i, item_feat, 1, action_type))
                # 记录曝光但未点击的物品
                if action_type == 0:  # 曝光但未点击
                    exposed_not_clicked.add(i)
                elif action_type == 1:  # 点击
                    clicked_items.add(i)
        
        # 初始化输出数组
        seq = np.zeros([self.maxlen + 1], dtype=np.int32)
        pos = np.zeros([self.maxlen + 1], dtype=np.int32)
        neg_local = np.zeros([self.maxlen + 1, self.num_local_neg], dtype=np.int32)  # 局部负样本
        neg_global = np.zeros([self.maxlen + 1, self.num_global_neg], dtype=np.int32)  # 全局负样本
        token_type = np.zeros([self.maxlen + 1], dtype=np.int32)
        next_token_type = np.zeros([self.maxlen + 1], dtype=np.int32)
        next_action_type = np.zeros([self.maxlen + 1], dtype=np.int32)
        
        # 特征数组
        seq_feat = np.empty([self.maxlen + 1], dtype=object)
        pos_feat = np.empty([self.maxlen + 1], dtype=object)
        neg_local_feat = np.empty([self.maxlen + 1, self.num_local_neg], dtype=object)
        neg_global_feat = np.empty([self.maxlen + 1, self.num_global_neg], dtype=object)
        
        # 构建训练样本
        nxt = ext_user_sequence[-1]
        idx = self.maxlen
        
        for record_tuple in reversed(ext_user_sequence[:-1]):
            i, feat, type_, act_type = record_tuple
            next_i, next_feat, next_type, next_act_type = nxt
            
            # 填充缺失特征
            feat = self.fill_missing_feat(feat, i)
            next_feat = self.fill_missing_feat(next_feat, next_i)
            
            # 填充当前位置的信息
            seq[idx] = i
            token_type[idx] = type_
            next_token_type[idx] = next_type
            if next_act_type is not None:
                next_action_type[idx] = next_act_type
            seq_feat[idx] = feat
            
            # 根据下一个token的类型处理
            if next_type == 1 and next_i != 0:
                pos[idx] = next_i
                pos_feat[idx] = next_feat
                
                if next_act_type == 1:  # 点击样本
                    # 采样局部负样本（当前序列曝光未点击的物品）
                    local_neg_samples = []
                    if exposed_not_clicked:
                        num_available = min(self.num_local_neg, len(exposed_not_clicked))
                        local_neg_samples = np.random.choice(
                            list(exposed_not_clicked), num_available, replace=False
                        )
                    
                    # 填充局部负样本
                    for j in range(self.num_local_neg):
                        if j < len(local_neg_samples):
                            neg_local[idx, j] = local_neg_samples[j]
                            neg_local_feat[idx, j] = self.fill_missing_feat(
                                self.item_feat_dict[str(local_neg_samples[j])], local_neg_samples[j]
                            )
                        else:
                            # 如果没有足够的局部负样本，使用随机负采样
                            neg_id = self._random_neq(1, self.itemnum + 1, clicked_items)
                            neg_local[idx, j] = neg_id
                            neg_local_feat[idx, j] = self.fill_missing_feat(
                                self.item_feat_dict[str(neg_id)], neg_id
                            )
                    
                    # 采样全局负样本（全局未曝光物品）
                    for j in range(self.num_global_neg):
                        neg_id = self._random_neq(1, self.itemnum + 1, clicked_items | exposed_not_clicked)
                        neg_global[idx, j] = neg_id
                        neg_global_feat[idx, j] = self.fill_missing_feat(
                            self.item_feat_dict[str(neg_id)], neg_id
                        )
                
                elif next_act_type == 0:  # 曝光未点击样本
                    # 对于曝光未点击样本，我们不需要负样本，但需要记录
                    pass
            
            nxt = record_tuple
            idx -= 1
            if idx == -1:
                break
        
        # 处理缺失特征
        seq_feat = np.where(seq_feat == None, self.feature_default_value, seq_feat)
        pos_feat = np.where(pos_feat == None, self.feature_default_value, pos_feat)
        
        for j in range(self.num_local_neg):
            neg_local_feat[:, j] = np.where(
                neg_local_feat[:, j] == None, self.feature_default_value, neg_local_feat[:, j]
            )
        
        for j in range(self.num_global_neg):
            neg_global_feat[:, j] = np.where(
                neg_global_feat[:, j] == None, self.feature_default_value, neg_global_feat[:, j]
            )
        
        return (seq, pos, neg_local, neg_global, token_type, next_token_type, 
                next_action_type, seq_feat, pos_feat, neg_local_feat, neg_global_feat)

    @staticmethod
    def collate_fn(batch):
        """批处理函数，支持新的数据结构"""
        # 解包batch数据
        (seq, pos, neg_local, neg_global, token_type, next_token_type, 
         next_action_type, seq_feat, pos_feat, neg_local_feat, neg_global_feat) = zip(*batch)
        
        # 将ID类数据转换为torch.Tensor
        seq = torch.from_numpy(np.array(seq))
        pos = torch.from_numpy(np.array(pos))
        neg_local = torch.from_numpy(np.array(neg_local))
        neg_global = torch.from_numpy(np.array(neg_global))
        token_type = torch.from_numpy(np.array(token_type))
        next_token_type = torch.from_numpy(np.array(next_token_type))
        next_action_type = torch.from_numpy(np.array(next_action_type))
        
        # 特征类数据保持list形式
        seq_feat = list(seq_feat)
        pos_feat = list(pos_feat)
        neg_local_feat = list(neg_local_feat)
        neg_global_feat = list(neg_global_feat)
        
        return (seq, pos, neg_local, neg_global, token_type, next_token_type, 
                next_action_type, seq_feat, pos_feat, neg_local_feat, neg_global_feat)

class BaselineModel(torch.nn.Module):
    def forward(self, seq, pos, neg_local, neg_global, token_type, next_token_type, 
                next_action_type, seq_feat, pos_feat, neg_local_feat, neg_global_feat):
        """
        前向传播，支持新的损失函数计算
        """
        # 获取用户序列表示
        user_emb = self.log2feats(seq, token_type, seq_feat)
        
        # 获取正样本表示
        pos_emb = self.get_item_embedding(pos, pos_feat)
        
        # 获取局部负样本表示
        neg_local_emb = []
        for j in range(neg_local.size(2)):  # 遍历每个局部负样本位置
            neg_local_j = neg_local[:, :, j]
            neg_local_feat_j = [feat[:, j] for feat in neg_local_feat]
            neg_local_emb.append(self.get_item_embedding(neg_local_j, neg_local_feat_j))
        neg_local_emb = torch.stack(neg_local_emb, dim=2)  # [batch_size, seq_len, num_local_neg, emb_dim]
        
        # 获取全局负样本表示
        neg_global_emb = []
        for j in range(neg_global.size(2)):  # 遍历每个全局负样本位置
            neg_global_j = neg_global[:, :, j]
            neg_global_feat_j = [feat[:, j] for feat in neg_global_feat]
            neg_global_emb.append(self.get_item_embedding(neg_global_j, neg_global_feat_j))
        neg_global_emb = torch.stack(neg_global_emb, dim=2)  # [batch_size, seq_len, num_global_neg, emb_dim]
        
        # 计算点击率预测
        pos_logits = torch.sum(user_emb * pos_emb, dim=-1)  # [batch_size, seq_len]
        
        neg_local_logits = torch.sum(
            user_emb.unsqueeze(2) * neg_local_emb, dim=-1
        )  # [batch_size, seq_len, num_local_neg]
        
        neg_global_logits = torch.sum(
            user_emb.unsqueeze(2) * neg_global_emb, dim=-1
        )  # [batch_size, seq_len, num_global_neg]
        
        return pos_logits, neg_local_logits, neg_global_logits

    def get_item_embedding(self, item_ids, item_feats):
        """获取物品embedding"""
        # 基础物品embedding
        item_emb = self.item_emb(item_ids)
        
        # 添加位置编码
        seq_len = item_ids.size(1)
        pos_emb = self.pos_emb(torch.arange(seq_len, device=item_ids.device))
        item_emb = item_emb + pos_emb
        
        # 处理物品特征
        if hasattr(self, 'feat2emb'):
            item_feat_emb = self.feat2emb(item_feats, 'item')
            item_emb = item_emb + item_feat_emb
        
        # 通过物品DNN
        item_emb = self.itemdnn(item_emb)
        
        return item_emb

### 3. 实现新的损失函数

```python
class HybridLoss(torch.nn.Module):
    def __init__(self, temperature=0.05, margin=0.2):
        super(HybridLoss, self).__init__()
        self.temperature = temperature
        self.margin = margin
        self.bce_loss = torch.nn.BCEWithLogitsLoss(reduction='none')
    
    def forward(self, pos_logits, neg_local_logits, neg_global_logits, next_action_type):
        """
        计算混合损失函数
        
        Args:
            pos_logits: 正样本的预测得分 [batch_size, seq_len]
            neg_local_logits: 局部负样本的预测得分 [batch_size, seq_len, num_local_neg]
            neg_global_logits: 全局负样本的预测得分 [batch_size, seq_len, num_global_neg]
            next_action_type: 下一个token的动作类型 [batch_size, seq_len]
        
        Returns:
            total_loss: 总损失
            loss_details: 损失详情字典
        """
        # 创建mask，只处理有效位置
        valid_mask = (next_action_type != 0).float()  # 1表示有效位置
        
        # 1. 点击样本的对比损失
        click_mask = (next_action_type == 1).float()  # 1表示点击样本
        
        if click_mask.sum() > 0:
            # 获取点击样本的位置
            click_indices = torch.nonzero(click_mask.view(-1)).squeeze(-1)
            
            # 提取点击样本的logits
            click_pos_logits = pos_logits.view(-1)[click_indices]
            click_neg_local_logits = neg_local_logits.view(-1, neg_local_logits.size(-1))[click_indices]
            click_neg_global_logits = neg_global_logits.view(-1, neg_global_logits.size(-1))[click_indices]
            
            # 计算对比损失
            click_loss = self._compute_contrastive_loss(
                click_pos_logits, click_neg_local_logits, click_neg_global_logits
            )
        else:
            click_loss = torch.tensor(0.0, device=pos_logits.device)
        
        # 2. 曝光未点击样本的损失
        expose_mask = (next_action_type == 0).float()  # 1表示曝光未点击样本
        
        if expose_mask.sum() > 0:
            # 获取曝光未点击样本的位置
            expose_indices = torch.nonzero(expose_mask.view(-1)).squeeze(-1)
            
            # 提取曝光未点击样本的logits
            expose_pos_logits = pos_logits.view(-1)[expose_indices]
            
            # 计算曝光未点击样本的损失（降低其点击率预测）
            expose_loss = self._compute_expose_loss(expose_pos_logits)
        else:
            expose_loss = torch.tensor(0.0, device=pos_logits.device)
        
        # 3. 组合损失
        total_loss = click_loss + 0.5 * expose_loss  # 可以调整权重
        
        # 损失详情
        loss_details = {
            'total_loss': total_loss.item(),
            'click_loss': click_loss.item(),
            'expose_loss': expose_loss.item()
        }
        
        return total_loss, loss_details
    
    def _compute_contrastive_loss(self, pos_logits, neg_local_logits, neg_global_logits):
        """
        计算点击样本的对比损失
        """
        batch_size = pos_logits.size(0)
        
        # 合并所有负样本logits
        all_neg_logits = torch.cat([neg_local_logits, neg_global_logits], dim=1)  # [batch_size, num_local_neg + num_global_neg]
        
        # 应用温度系数
        pos_logits = pos_logits / self.temperature
        all_neg_logits = all_neg_logits / self.temperature
        
        # 计算交叉熵损失
        logits = torch.cat([pos_logits.unsqueeze(1), all_neg_logits], dim=1)  # [batch_size, 1 + num_local_neg + num_global_neg]
        labels = torch.zeros(batch_size, dtype=torch.long, device=pos_logits.device)
        
        loss = F.cross_entropy(logits, labels)
        
        return loss
    
    def _compute_expose_loss(self, pos_logits):
        """
        计算曝光未点击样本的损失（降低其点击率预测）
        """
        # 使用BCE损失，目标为0（不点击）
        target = torch.zeros_like(pos_logits)
        loss = self.bce_loss(pos_logits, target).mean()
        
        return loss
```

## 优势分析

这种混合损失函数设计具有以下优势：

1. **充分利用曝光序列信息**：
   - 点击样本提供正信号
   - 曝光未点击样本提供明确的负信号

2. **多样化的负样本**：
   - 局部负样本（当前序列曝光未点击）：更具挑战性，因为它们已经被系统推荐
   - 全局负样本（全局未曝光）：保证多样性，避免模型过拟合于局部模式

3. **明确的优化目标**：
   - 对于点击样本：最大化其得分，最小化负样本得分
   - 对于曝光未点击样本：直接降低其点击率预测

4. **符合实际场景**：
   - 真实推荐系统中，我们既需要提高点击物品的排名，也需要降低曝光但未点击物品的排名

## 实施

1. **逐步实施**：
   - 首先实现基本的混合损失函数
   - 然后调整负样本数量和温度系数等超参数
   - 最后可以尝试更复杂的负采样策略

2. **超参数调优**：
   - `num_local_neg`：建议从3开始，根据效果调整
   - `num_global_neg`：建议从2开始，根据效果调整
   - `temperature`：控制对比损失的尖锐程度，建议从0.05开始
   - 损失权重：点击损失和曝光损失之间的权重，建议从1:0.5开始

3. **监控训练过程**：
   - 分别监控点击损失和曝光损失的变化
   - 确保两种损失都能有效下降

## 任务目标分析

当前任务的核心目标是：
1. **HitRate@10**：正样本是否出现在Top-10推荐列表中
2. **NDCG@10**：正样本在推荐列表中的排名位置

因此，损失函数应该：
1. 确保正样本得分高于负样本（对比学习）
2. 优化正样本在推荐列表中的排名（排序学习）
3. 特别关注Top-10位置的性能（因为评估指标是@10）

## 改进后的混合损失函数

```python
class TaskAwareHybridLoss(torch.nn.Module):
    def __init__(self, temperature=0.05, top_k=10, alpha=0.7, beta=0.3):
        """
        任务感知的混合损失函数
        
        Args:
            temperature: 对比损失的温度系数
            top_k: 评估指标中的K值（HitRate@K, NDCG@K）
            alpha: 排序损失的权重
            beta: 对比损失的权重
        """
        super(TaskAwareHybridLoss, self).__init__()
        self.temperature = temperature
        self.top_k = top_k
        self.alpha = alpha  # 排序损失权重
        self.beta = beta   # 对比损失权重
        self.bce_loss = torch.nn.BCEWithLogitsLoss(reduction='none')
    
    def forward(self, pos_logits, neg_local_logits, neg_global_logits, next_action_type):
        """
        计算任务感知的混合损失
        
        Args:
            pos_logits: 正样本的预测得分 [batch_size, seq_len]
            neg_local_logits: 局部负样本的预测得分 [batch_size, seq_len, num_local_neg]
            neg_global_logits: 全局负样本的预测得分 [batch_size, seq_len, num_global_neg]
            next_action_type: 下一个token的动作类型 [batch_size, seq_len]
        
        Returns:
            total_loss: 总损失
            loss_details: 损失详情字典
        """
        # 创建mask，只处理有效位置
        valid_mask = (next_action_type != 0).float()
        
        # 1. 点击样本的损失
        click_mask = (next_action_type == 1).float()
        
        if click_mask.sum() > 0:
            click_indices = torch.nonzero(click_mask.view(-1)).squeeze(-1)
            
            click_pos_logits = pos_logits.view(-1)[click_indices]
            click_neg_local_logits = neg_local_logits.view(-1, neg_local_logits.size(-1))[click_indices]
            click_neg_global_logits = neg_global_logits.view(-1, neg_global_logits.size(-1))[click_indices]
            
            # a) 排序损失（直接优化NDCG@K）
            ranking_loss = self._compute_ndcg_optimized_loss(
                click_pos_logits, click_neg_local_logits, click_neg_global_logits
            )
            
            # b) 对比损失（确保正样本高于负样本）
            contrastive_loss = self._compute_weighted_contrastive_loss(
                click_pos_logits, click_neg_local_logits, click_neg_global_logits
            )
            
            # c) Top-K感知损失（直接优化HitRate@K）
            topk_aware_loss = self._compute_topk_aware_loss(
                click_pos_logits, click_neg_local_logits, click_neg_global_logits
            )
            
            # 组合点击样本损失
            click_loss = self.alpha * ranking_loss + self.beta * contrastive_loss + 0.5 * topk_aware_loss
        else:
            click_loss = torch.tensor(0.0, device=pos_logits.device)
            ranking_loss = torch.tensor(0.0, device=pos_logits.device)
            contrastive_loss = torch.tensor(0.0, device=pos_logits.device)
            topk_aware_loss = torch.tensor(0.0, device=pos_logits.device)
        
        # 2. 曝光未点击样本的损失
        expose_mask = (next_action_type == 0).float()
        
        if expose_mask.sum() > 0:
            expose_indices = torch.nonzero(expose_mask.view(-1)).squeeze(-1)
            expose_pos_logits = pos_logits.view(-1)[expose_indices]
            expose_loss = self._compute_expose_loss(expose_pos_logits)
        else:
            expose_loss = torch.tensor(0.0, device=pos_logits.device)
        
        # 3. 总损失
        total_loss = click_loss + 0.3 * expose_loss
        
        # 损失详情
        loss_details = {
            'total_loss': total_loss.item(),
            'click_loss': click_loss.item(),
            'ranking_loss': ranking_loss.item(),
            'contrastive_loss': contrastive_loss.item(),
            'topk_aware_loss': topk_aware_loss.item(),
            'expose_loss': expose_loss.item()
        }
        
        return total_loss, loss_details
    
    def _compute_ndcg_optimized_loss(self, pos_logits, neg_local_logits, neg_global_logits):
        """
        计算NDCG优化的排序损失
        使用LambdaRank的思想，直接优化NDCG指标
        """
        batch_size = pos_logits.size(0)
        
        # 合并所有样本（正样本 + 局部负样本 + 全局负样本）
        all_logits = torch.cat([
            pos_logits.unsqueeze(1), 
            neg_local_logits, 
            neg_global_logits
        ], dim=1)  # [batch_size, 1 + num_local_neg + num_global_neg]
        
        # 创建标签：正样本为1，负样本为0
        labels = torch.zeros(batch_size, all_logits.size(1), device=pos_logits.device)
        labels[:, 0] = 1  # 第一个是正样本
        
        # 计算理想DCG (IDCG)
        ideal_dcg = self._compute_dcg(torch.ones_like(labels), labels, self.top_k)
        
        # 计算预测排序的DCG
        # 首先获取预测排序
        _, pred_indices = torch.sort(all_logits, dim=1, descending=True)
        # 创建排序后的标签
        sorted_labels = torch.gather(labels, 1, pred_indices)
        # 计算DCG
        pred_dcg = self._compute_dcg(all_logits, sorted_labels, self.top_k)
        
        # 计算NDCG
        ndcg = pred_dcg / (ideal_dcg + 1e-10)
        
        # 损失：1 - NDCG（最小化这个损失相当于最大化NDCG）
        loss = (1 - ndcg).mean()
        
        return loss
    
    def _compute_dcg(self, scores, labels, k):
        """
        计算DCG@K
        """
        k = min(k, labels.size(1))
        
        # 计算位置折扣
        discounts = torch.log2(torch.arange(2, k+2, dtype=torch.float, device=scores.device))
        
        # 计算DCG
        dcg = (labels[:, :k] / discounts).sum(dim=1)
        
        return dcg
    
    def _compute_weighted_contrastive_loss(self, pos_logits, neg_local_logits, neg_global_logits):
        """
        计算加权的对比损失
        给局部负样本更高权重，因为它们更难区分
        """
        # 负样本权重：局部负样本权重更高
        neg_local_weight = 2.0
        neg_global_weight = 1.0
        
        # 应用权重
        weighted_neg_local = neg_local_logits * neg_local_weight
        weighted_neg_global = neg_global_logits * neg_global_weight
        
        # 合并所有负样本
        all_neg_logits = torch.cat([weighted_neg_local, weighted_neg_global], dim=1)
        
        # 应用温度系数
        pos_logits = pos_logits / self.temperature
        all_neg_logits = all_neg_logits / self.temperature
        
        # 计算交叉熵损失
        logits = torch.cat([pos_logits.unsqueeze(1), all_neg_logits], dim=1)
        labels = torch.zeros(pos_logits.size(0), dtype=torch.long, device=pos_logits.device)
        
        loss = F.cross_entropy(logits, labels)
        
        return loss
    
    def _compute_topk_aware_loss(self, pos_logits, neg_local_logits, neg_global_logits):
        """
        计算Top-K感知损失，直接优化HitRate@K
        确保正样本在Top-K中
        """
        batch_size = pos_logits.size(0)
        
        # 合并所有样本
        all_logits = torch.cat([
            pos_logits.unsqueeze(1), 
            neg_local_logits, 
            neg_global_logits
        ], dim=1)  # [batch_size, 1 + num_local_neg + num_global_neg]
        
        # 获取Top-K的索引
        _, topk_indices = torch.topk(all_logits, self.top_k, dim=1)
        
        # 检查正样本（索引0）是否在Top-K中
        pos_in_topk = (topk_indices == 0).any(dim=1).float()
        
        # 计算损失：如果正样本不在Top-K中，则产生损失
        # 使用sigmoid来平滑损失
        loss = torch.sigmoid(-pos_logits * 5) * (1 - pos_in_topk)
        loss = loss.mean()
        
        return loss
    
    def _compute_expose_loss(self, pos_logits):
        """
        计算曝光未点击样本的损失
        降低其点击率预测
        """
        # 使用BCE损失，目标为0（不点击）
        target = torch.zeros_like(pos_logits)
        loss = self.bce_loss(pos_logits, target).mean()
        
        return loss
```

## 关键改进点说明

### 1. NDCG优化的排序损失
- **目标**：直接优化NDCG@10指标
- **方法**：使用LambdaRank的思想，计算预测排序的NDCG，并最小化1-NDCG
- **优势**：直接针对评估指标进行优化，更符合任务目标

### 2. 加权对比损失
- **目标**：确保正样本得分高于负样本
- **方法**：给局部负样本（曝光未点击）更高权重（2.0），因为它们更难区分
- **优势**：更关注困难样本，提高模型区分能力

### 3. Top-K感知损失
- **目标**：直接优化HitRate@10指标
- **方法**：检查正样本是否在Top-10中，如果不在则产生损失
- **优势**：直接针对HitRate@K进行优化，确保正样本出现在推荐列表的前列

### 4. 损失组合策略
- **排序损失（α=0.7）**：主要优化NDCG@10
- **对比损失（β=0.3）**：辅助优化，确保正样本高于负样本
- **Top-K感知损失（0.5）**：辅助优化，确保HitRate@10
- **曝光损失（0.3）**：降低曝光未点击样本的得分

## 1. 排序操作的不可导性问题

### 问题分析
`_compute_ndcg_optimized_loss`和`_compute_topk_aware_loss`中使用了`torch.sort`和`torch.topk`，这些操作会阻断梯度流，导致模型无法通过这些损失学习。

### 解决方案
我们需要使用可导的近似方法来替代这些不可导的操作：

```python
def _compute_differentiable_ranking_loss(self, pos_logits, neg_local_logits, neg_global_logits):
    """
    使用ListNet作为可导的排序损失近似
    """
    batch_size = pos_logits.size(0)
    
    # 合并所有样本
    all_logits = torch.cat([
        pos_logits.unsqueeze(1),
        neg_local_logits,
        neg_global_logits
    ], dim=1)
    
    # 创建标签：正样本为1，负样本为0
    labels = torch.zeros(batch_size, all_logits.size(1), device=pos_logits.device)
    labels[:, 0] = 1  # 第一个是正样本
    
    # 计算Top-K的概率分布（使用Softmax作为近似）
    top_k = min(self.top_k, all_logits.size(1))
    
    # 使用Softmax计算概率分布，近似排序
    probs = F.softmax(all_logits / self.temperature, dim=1)
    
    # 计算理想概率分布（正样本在第一位）
    ideal_probs = torch.zeros_like(probs)
    ideal_probs[:, 0] = 1.0
    
    # 计算KL散度作为ListNet损失
    loss = F.kl_div(
        torch.log(probs + 1e-10), 
        ideal_probs, 
        reduction='batchmean'
    )
    
    return loss
```

## 2. 加权对比损失的数值稳定性问题

### 问题分析
在`_compute_weighted_contrastive_loss`中，直接用常数乘以logits确实会导致数值不稳定。这种做法会使局部负样本的logits值变大或变小，影响softmax的分布，可能导致梯度消失或爆炸。

### 解决方案
我们应该在损失计算阶段应用权重，而不是直接修改logits：

```python
def _compute_stable_weighted_contrastive_loss(self, pos_logits, neg_local_logits, neg_global_logits):
    """
    数值稳定的加权对比损失
    """
    batch_size = pos_logits.size(0)
    
    # 合并所有负样本
    all_neg_logits = torch.cat([neg_local_logits, neg_global_logits], dim=1)
    
    # 计算正样本与负样本之间的差异
    pos_expanded = pos_logits.unsqueeze(1).expand(-1, all_neg_logits.size(1))
    
    # 计算差异：正样本logits - 负样本logits
    diffs = pos_expanded - all_neg_logits
    
    # 创建权重：局部负样本权重更高
    weights = torch.ones_like(diffs)
    weights[:, :neg_local_logits.size(1)] = 2.0  # 局部负样本权重为2.0
    
    # 应用温度系数
    scaled_diffs = diffs / self.temperature
    
    # 计算加权交叉熵损失
    # 使用logsigmoid而不是softmax，更稳定
    losses = F.logsigmoid(scaled_diffs)
    weighted_losses = losses * weights
    
    # 平均损失
    loss = -weighted_losses.mean()
    
    return loss
```

## 3. 曝光损失的问题

### 问题分析
在`_compute_expose_loss`中，变量名有歧义。这里的`pos_logits`实际上是曝光未点击样本的logits，而不是正样本的logits。这会导致损失计算错误，给模型提供错误的训练信号。

### 解决方案
明确使用曝光未点击样本的logits，并改进损失计算：

```python
def _compute_corrected_expose_loss(self, expose_logits):
    """
    修正的曝光未点击样本损失
    """
    # 使用BCE损失，目标为0（不点击）
    target = torch.zeros_like(expose_logits)
    
    # 使用带温度系数的BCE损失，使损失更加平滑
    scaled_logits = expose_logits / self.temperature
    loss = F.binary_cross_entropy_with_logits(scaled_logits, target).mean()
    
    return loss
```

## 4. 其他深层次问题分析

### 4.1 损失权重设置不当
原始实现中，alpha=0.7, beta=0.3过于强调排序损失，而对比损失权重不足。考虑到排序损失可能因为不可导性而失效，这会导致整体训练效果下降。

### 4.2 温度系数设置过小
temperature=0.05过小，导致对比损失过于尖锐，可能使模型过拟合于当前batch的样本。

### 4.3 Top-K感知损失的设计问题
原始实现中，`torch.sigmoid(-pos_logits * 5) * (1 - pos_in_topk)`这个公式可能导致损失值非常小，因为：
1. `pos_in_topk`在大多数情况下可能为1（正样本在Top-K中）
2. 即使`pos_in_topk`为0，`sigmoid(-pos_logits * 5)`也可能非常小

### 4.4 损失组合策略问题
将多个损失简单相加可能导致它们之间的冲突，特别是当某些损失失效时。

## 5. 完整的改进方案

```python
class TaskAwareHybridLoss(torch.nn.Module):
    def __init__(self, temperature=0.1, top_k=10, alpha=0.4, beta=0.5, gamma=0.3):
        """
        修正后的任务感知混合损失函数
        
        Args:
            temperature: 对比损失的温度系数，增大以提高稳定性
            top_k: 评估指标中的K值
            alpha: 排序损失的权重，降低以避免过度依赖
            beta: 对比损失的权重，增加作为主要损失
            gamma: 曝光损失的权重
        """
        super(FixedTaskAwareHybridLoss, self).__init__()
        self.temperature = temperature
        self.top_k = top_k
        self.alpha = alpha
        self.beta = beta
        self.gamma = gamma
        self.bce_loss = torch.nn.BCEWithLogitsLoss(reduction='none')
    
    def forward(self, pos_logits, neg_local_logits, neg_global_logits, next_action_type):
        # 创建mask，只处理有效位置
        valid_mask = (next_action_type != 0).float()
        
        # 1. 点击样本的损失
        click_mask = (next_action_type == 1).float()
        
        if click_mask.sum() > 0:
            click_indices = torch.nonzero(click_mask.view(-1)).squeeze(-1)
            
            click_pos_logits = pos_logits.view(-1)[click_indices]
            click_neg_local_logits = neg_local_logits.view(-1, neg_local_logits.size(-1))[click_indices]
            click_neg_global_logits = neg_global_logits.view(-1, neg_global_logits.size(-1))[click_indices]
            
            # a) 可导的排序损失（使用ListNet近似）
            ranking_loss = self._compute_differentiable_ranking_loss(
                click_pos_logits, click_neg_local_logits, click_neg_global_logits
            )
            
            # b) 稳定的加权对比损失
            contrastive_loss = self._compute_stable_weighted_contrastive_loss(
                click_pos_logits, click_neg_local_logits, click_neg_global_logits
            )
            
            # c) 可导的Top-K感知损失
            topk_aware_loss = self._compute_differentiable_topk_loss(
                click_pos_logits, click_neg_local_logits, click_neg_global_logits
            )
            
            # 组合点击样本损失，调整权重
            click_loss = self.alpha * ranking_loss + self.beta * contrastive_loss + 0.2 * topk_aware_loss
        else:
            click_loss = torch.tensor(0.0, device=pos_logits.device)
            ranking_loss = torch.tensor(0.0, device=pos_logits.device)
            contrastive_loss = torch.tensor(0.0, device=pos_logits.device)
            topk_aware_loss = torch.tensor(0.0, device=pos_logits.device)
        
        # 2. 曝光未点击样本的损失
        expose_mask = (next_action_type == 0).float()
        
        if expose_mask.sum() > 0:
            expose_indices = torch.nonzero(expose_mask.view(-1)).squeeze(-1)
            expose_logits = pos_logits.view(-1)[expose_indices]  # 曝光未点击样本的logits
            expose_loss = self._compute_corrected_expose_loss(expose_logits)
        else:
            expose_loss = torch.tensor(0.0, device=pos_logits.device)
        
        # 3. 总损失
        total_loss = click_loss + self.gamma * expose_loss
        
        # 损失详情
        loss_details = {
            'total_loss': total_loss.item(),
            'click_loss': click_loss.item(),
            'ranking_loss': ranking_loss.item(),
            'contrastive_loss': contrastive_loss.item(),
            'topk_aware_loss': topk_aware_loss.item(),
            'expose_loss': expose_loss.item()
        }
        
        return total_loss, loss_details
    
    def _compute_differentiable_ranking_loss(self, pos_logits, neg_local_logits, neg_global_logits):
        """使用ListNet作为可导的排序损失近似"""
        batch_size = pos_logits.size(0)
        
        # 合并所有样本
        all_logits = torch.cat([
            pos_logits.unsqueeze(1),
            neg_local_logits,
            neg_global_logits
        ], dim=1)
        
        # 创建标签：正样本为1，负样本为0
        labels = torch.zeros(batch_size, all_logits.size(1), device=pos_logits.device)
        labels[:, 0] = 1
        
        # 使用Softmax计算概率分布，近似排序
        probs = F.softmax(all_logits / self.temperature, dim=1)
        
        # 计算理想概率分布（正样本在第一位）
        ideal_probs = torch.zeros_like(probs)
        ideal_probs[:, 0] = 1.0
        
        # 计算KL散度作为ListNet损失
        loss = F.kl_div(
            torch.log(probs + 1e-10), 
            ideal_probs, 
            reduction='batchmean'
        )
        
        return loss
    
    def _compute_stable_weighted_contrastive_loss(self, pos_logits, neg_local_logits, neg_global_logits):
        """数值稳定的加权对比损失"""
        batch_size = pos_logits.size(0)
        
        # 合并所有负样本
        all_neg_logits = torch.cat([neg_local_logits, neg_global_logits], dim=1)
        
        # 计算正样本与负样本之间的差异
        pos_expanded = pos_logits.unsqueeze(1).expand(-1, all_neg_logits.size(1))
        diffs = pos_expanded - all_neg_logits
        
        # 创建权重：局部负样本权重更高
        weights = torch.ones_like(diffs)
        weights[:, :neg_local_logits.size(1)] = 2.0  # 局部负样本权重为2.0
        
        # 应用温度系数
        scaled_diffs = diffs / self.temperature
        
        # 计算加权交叉熵损失
        losses = F.logsigmoid(scaled_diffs)
        weighted_losses = losses * weights
        
        # 平均损失
        loss = -weighted_losses.mean()
        
        return loss
    
    def _compute_differentiable_topk_loss(self, pos_logits, neg_local_logits, neg_global_logits):
        """可导的Top-K感知损失"""
        batch_size = pos_logits.size(0)
        
        # 合并所有样本
        all_logits = torch.cat([
            pos_logits.unsqueeze(1),
            neg_local_logits,
            neg_global_logits
        ], dim=1)
        
        # 计算Soft Top-K概率
        top_k = min(self.top_k, all_logits.size(1))
        
        # 使用Softmax作为Top-K的近似
        probs = F.softmax(all_logits / self.temperature, dim=1)
        
        # 计算正样本（索引0）的排名概率
        # 我们希望正样本在Top-K中，即其概率应该较高
        pos_prob = probs[:, 0]
        
        # 计算Top-K的总概率
        topk_probs, _ = torch.topk(probs, top_k, dim=1)
        topk_total_prob = topk_probs.sum(dim=1)
        
        # 计算损失：最大化正样本在Top-K中的概率
        # 使用负对数似然
        loss = -torch.log(pos_prob + 1e-10) * (1 - pos_prob / topk_total_prob)
        
        return loss.mean()
    
    def _compute_corrected_expose_loss(self, expose_logits):
        """修正的曝光未点击样本损失"""
        # 使用BCE损失，目标为0（不点击）
        target = torch.zeros_like(expose_logits)
        
        # 使用带温度系数的BCE损失，使损失更加平滑
        scaled_logits = expose_logits / self.temperature
        loss = F.binary_cross_entropy_with_logits(scaled_logits, target).mean()
        
        return loss
```

## 6. 为什么原始实现导致性能下降的根本原因

除了上述技术问题，原始实现导致性能下降的根本原因还包括：

1. **梯度阻断导致部分损失失效**：排序操作的不可导性导致模型无法通过这些损失学习，相当于只使用了部分损失函数，这直接降低了模型的学习能力。

2. **数值不稳定导致训练困难**：直接修改logits值导致梯度消失或爆炸，使训练过程不稳定，模型难以收敛。

3. **曝光损失计算错误**：使用了错误的logits计算曝光损失，给模型提供了错误的训练信号，导致模型学习到错误的模式。

4. **损失权重设置不当**：过度依赖可能失效的排序损失，而对比损失权重不足，导致整体训练效果下降。

5. **Top-K损失几乎为0**：由于实现问题，Top-K感知损失可能非常小，对模型训练几乎没有贡献，进一步降低了模型的学习能力。

## 7. 实施建议

1. **优先实施对比损失**：首先只使用改进的对比损失，确保基本功能正常，这是最稳定和最重要的损失组件。

2. **逐步添加其他损失**：在对比损失稳定后，逐步添加可导的排序损失和Top-K感知损失。

3. **调整超参数**：
   - 增大温度系数（0.1或更高）
   - 调整损失权重，增加对比损失的权重
   - 可能需要调整负样本数量

4. **监控训练过程**：
   - 分别记录各个损失组件的值
   - 确保所有损失都能正常下降
   - 监控梯度大小，避免梯度消失或爆炸

5. **验证集评估**：在验证集上计算实际的HitRate@10和NDCG@10，确保损失函数的改进确实转化为评估指标的提升。

这个修正版的损失函数应该能够解决原始实现中的问题，并提供更稳定的训练过程和更好的性能。特别是通过解决梯度阻断和数值稳定性问题，应该能够显著提升模型的表现。
