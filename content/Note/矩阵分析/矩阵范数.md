1.
非负性证明

鉴于$A$为$n$阶正定Hermite矩阵，根据正定矩阵的定义，对于任意非零向量$X \in \mathbb{C}^n$，对应的二次型$X^H A X$必为正实数。因此，$\|X\|_A = \sqrt{X^H A X} \geq 0$恒成立。且当$|X|_A = 0$时，即$X^H A X = 0$，由$A$的正定性可知仅当$X = 0$时成立。这满足了向量范数的非负性条件。

齐次性证明

对于任意复数$k \in \mathbb{C}$及向量$X \in \mathbb{C}^n$，考察$|kX|_A$。代入定义式可得 $\|kX\|_A = \sqrt{(kX)^H A (kX)} = \sqrt{\bar{k} X^H A k X} = \sqrt{\bar{k}k (X^H A X)} = \sqrt{|k|^2 X^H A X} = |k|\sqrt{X^H A X} = |k|\|X\|_A$。

三角不等式证明

由于$A$是正定Hermite矩阵，存在Cholesky分解$A = L L^H$，其中$L$为可逆矩阵。于是可以将范数表达式重写为 $\|X\|_A = \sqrt{X^H L L^H X} = \sqrt{(L^H X)^H (L^H X)} = \|L^H X\|_2$，即该范数等价于向量$L^H X$的欧氏范数（2-范数）。对于任意$X, Y \in \mathbb{C}^n$，应用欧氏范数的三角不等式性质，可得 $\|X+Y\|_A = \|L^H(X+Y)\|_2 = \|L^H X + L^H Y\|_2 \leq \|L^H X\|_2 + \|L^H Y\|_2 = \|X\|_A + \|Y\|_A$。至此，三个条件均获证，$\|X\|_A$确为$\mathbb{C}^n$上的向量范数。


2.

转化与非负性证明

观察给定的表达式 $\|x\| = (|2x_1 - 3ix_2 + x_3|^2 + |x_2 - 2x_3|^2 + |x_1 + x_3|^2)^{1/2}$，可将其视为$\mathbb{C}^3$上的欧氏范数$|Bx|_2$，其中线性变换矩阵$B$定义为：

$$B = \begin{pmatrix} 2 & -3i & 1 \\ 0 & 1 & -2 \\ 1 & 0 & 1 \end{pmatrix}$$

计算矩阵$B$的行列式：$\det(B) = 2(1 - 0) - (-3i)(0 - (-2)) + 1(0 - 1) = 2 - 6i - 1 = 1 - 6i \neq 0$。由于$\det(B) \neq 0$，矩阵$B$是非奇异的（满秩）。根据非奇异线性变换的性质，$\|x\| = \|Bx\|_2 \ge 0$，且$|x| = 0 \iff |Bx|_2 = 0 \iff Bx = 0$。因$B$可逆，这仅在$x=0$时成立，故非负性得证。

齐次性与三角不等式证明

利用欧氏范数$|\cdot|_2$的性质进行推导。对于任意$k \in \mathbb{C}$，$|kx| = |B(kx)|_2 = |k(Bx)|_2 = |k||Bx|_2 = |k||x|$，满足齐次性。对于任意$x, y \in \mathbb{C}^3$，根据欧氏范数的三角不等式，有 $\|x+y\| = \|B(x+y)\|_2 = \|Bx + By\|_2 \leq \|Bx\|_2 + \|By\|_2 = \|x\| + \|y\|$。因此，该表达式满足向量范数的所有公理。

3.

非负性、齐次性与三角不等式证明

设$\mu(m,n) = \max{m, n}$。

对于非负性：因$|a_{ij}| \ge 0$且$\mu(m,n) \ge 1$，故$|A|{m\infty} \ge 0$。若$|A|{m\infty} = 0$，则$\max |a_{ij}| = 0$，即所有元素为0，故$A=0$。

对于齐次性：$\|kA\|_{m_\infty} = \mu(m,n) \max |ka_{ij}| = \mu(m,n) |k| \max |a_{ij}| = |k| \|A\|_{m_\infty}$。

对于三角不等式：$\|A+B\|_{m_\infty} = \mu(m,n) \max_{i,j} |a_{ij} + b_{ij}| \le \mu(m,n) (\max |a_{ij}| + \max |b_{ij}|) = \|A\|_{m_\infty} + \|B\|_{m_\infty}$。

矩阵乘法相容性证明

设$A \in \mathbb{C}^{m \times n}, B \in \mathbb{C}^{n \times p}$，记$C = AB \in \mathbb{C}^{m \times p}$。令$\alpha = \max_{i,j} |a_{ij}|$，$\beta = \max_{j,k} |b_{jk}|$。则$C$中元素满足$|c_{ik}| = |\sum_{j=1}^n a_{ij} b_{jk}| \le \sum_{j=1}^n |a_{ij}||b_{jk}| \le n \alpha \beta$。

由此可得$|C|{m\infty} = \max{m, p} \max |c_{ik}| \le \max{m, p} \cdot n \cdot \alpha \beta$。

另一方面，$\|A\|_{m_\infty} \|B\|_{m_\infty} = \max\{m, n\} \alpha \cdot \max\{n, p\} \beta = \max\{m, n\} \max\{n, p\} \alpha \beta$。

要证$|AB|{m\infty} \le |A|{m\infty} |B|{m\infty}$，只需证明不等式 $\max\{m, p\} \cdot n \le \max\{m, n\} \cdot \max\{n, p\}$。

分情况讨论：

1. 若$n \ge m$且$n \ge p$，则不等式右端为$n^2$，左端$\le n^2$，成立。
    
2. 若$n < m$且$n < p$，则不等式右端为$mp$，左端为$\max{m, p}n < mp$，成立。
    
3. 若$m, n, p$大小交错（如$m > n > p$），右端为$mn$，左端为$mn$，成立。
    
    综上所述，该范数满足矩阵乘法的相容性，故为矩阵范数。

4.

计算矩阵$A$的特征多项式：

$$|\lambda I - A| = \begin{vmatrix} \lambda & -a & -a \\ -a & \lambda & -a \\ -a & -a & \lambda \end{vmatrix}$$

将第二行与第三行加到第一行，得公因子$(\lambda - 2a)$。随后通过列变换化简，可得特征多项式为 $(\lambda - 2a)(\lambda + a)^2$。因此，矩阵$A$的特征值为 $\lambda_1 = 2a, \lambda_2 = \lambda_3 = -a$。

谱半径与收敛条件判定

根据矩阵序列收敛的性质，$\lim_{k \to \infty} A^k = 0$ 的充分必要条件是矩阵$A$的谱半径 $\rho(A) < 1$。

矩阵$A$的谱半径为 $\rho(A) = \max\{|2a|, |-a|\} = 2|a|$。

由收敛条件 $\rho(A) < 1$ 可得不等式 $2|a| < 1$，解得 $|a| < \frac{1}{2}$。

故当 $-\frac{1}{2} < a < \frac{1}{2}$ 时，$\lim_{k \to \infty} A^k = 0$。

5.

设矩阵 $B = \begin{bmatrix} \frac{1}{6} & -\frac{1}{3} \\ -\frac{4}{3} & \frac{1}{6} \end{bmatrix}$。计算其特征方程：

$$|\lambda I - B| = \left(\lambda - \frac{1}{6}\right)^2 - \frac{4}{9} = 0$$

解得 $\lambda - \frac{1}{6} = \pm \frac{2}{3}$，即特征值为 $\lambda_1 = \frac{5}{6}$，$\lambda_2 = -\frac{1}{2}$。

因此，矩阵$B$的谱半径 $\rho(B) = \frac{5}{6}$。

所给级数为 $\sum_{k=0}^{\infty} k B^k$。考查对应的标量幂级数 $\sum_{k=0}^{\infty} k z^k$，根据达朗贝尔判别法，其收敛半径 $R = \lim_{k \to \infty} |\frac{k}{k+1}| = 1$。

根据矩阵幂级数收敛定理，当 $\rho(B) < R$ 时，矩阵级数绝对收敛。

因为 $\rho(B) = \frac{5}{6} < 1$，所以该矩阵幂级数收敛。

6.

由定义 $A = I - u u^H$ 且 $u$ 为单位向量（$u^H u = 1$）。首先验证$A$的Hermite性与幂等性：

$A^H = (I - u u^H)^H = I - (u^H)^H u^H = I - u u^H = A$。

$A^2 = (I - u u^H)(I - u u^H) = I - 2u u^H + u(u^H u)u^H = I - 2u u^H + u u^H = I - u u^H = A$。

因此，$A$是一个Hermite幂等矩阵，即正交投影矩阵。

由于$A$是Hermite矩阵，其谱范数 $\|A\|_2$ 等于其谱半径 $\rho(A)$。

作为投影矩阵，其特征值只能为0或1。由于$n > 1$，存在非零向量 $v$ 使得 $v \perp u$，此时 $Av = v$，即1是$A$的特征值。

因此 $\rho(A) = 1$，故 $\|A\|_2 = 1$。

对于任意 $X \in \mathbb{C}^n$，由于$A$是正交投影矩阵，空间可分解为 $X = AX + (I-A)X$，其中 $AX \in R(A)$ 且 $(I-A)X \in N(A) = R(A)^\perp$。根据勾股定理：

$$\|X\|_2^2 = \|AX\|_2^2 + \|(I-A)X\|_2^2$$

已知 $AX \neq X$，这意味着 $(I-A)X = X - AX \neq 0$，由范数的非负性知 $\|(I-A)X\|_2^2 > 0$。

从而 $\|X\|_2^2 - \|AX\|_2^2 > 0$，即 $\|AX\|_2 < \|X\|_2$。
