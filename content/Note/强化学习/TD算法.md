所有基于价值的强化学习算法，其根本目标是求解一个满足特定不动点（Fixed-Point）条件的价值函数。

*   **对于On-Policy方法（如Sarsa）**：其目标是求解策略 $\pi$ 下的状态-动作价值函数 $q_\pi(s, a)$。根据其定义，$q_\pi$ 必须满足**贝尔曼期望方程 (BE)**：
    $q_\pi(s, a) = \mathbb{E}[R_{t+1} + \gamma q_\pi(S_{t+1}, A_{t+1}) | S_t = s, A_t = a]$
    此处的期望 $\mathbb{E}[\cdot]$ 是对所有可能的后继状态 $S_{t+1}$、奖励 $R_{t+1}$ 以及后继动作 $A_{t+1}$ 求的。具体地，它依赖于未知的环境动态 $p(s', r | s, a)$ 和已知的当前策略 $\pi(a'|s')$。

*   **对于Off-Policy方法（如Q-Learning）**：其目标是求解最优状态-动作价值函数 $q_*(s, a)$。$q_*$ 必须满足**贝尔曼最优方程 (BOE)**：
    $q_*(s, a) = \mathbb{E}[R_{t+1} + \gamma \max_{a'} q_*(S_{t+1}, a') | S_t = s, A_t = a]$
    此处的期望仅依赖于未知的环境动态 $p(s', r | s, a)$。

**核心障碍**：在模型未知（Model-Free）的设定下，我们无法直接计算这两个方程右侧的期望值，因为环境动态 $p(s', r | s, a)$ 是未知的。因此，无法通过直接求解方程组或类似动态规划的方法来得到 $q_\pi$ 或 $q_*$。

#### **2. 基于采样的随机近似方法**

既然无法进行精确的期望计算，我们转向使用从环境中交互得到的**样本**来**近似**这个期望。这就是**随机近似**（Stochastic Approximation）的核心思想。

考虑一个一般的迭代求解过程。假设我们当前对价值函数的估计是 $q_t$。我们希望生成一个更好的估计 $q_{t+1}$。

1.  **目标值**：贝尔曼方程的右侧，即 $\mathbb{E}[\dots]$，是我们希望 $q_t(s_t, a_t)$ 逼近的理论目标。
2.  **采样估计**：我们无法计算这个目标，但可以通过在环境中执行 $(s_t, a_t)$ 获得一个具体的转移样本 $(r_{t+1}, s_{t+1})$。利用这个样本，我们可以构造一个对理论目标的**有噪声的估计**。我们将这个估计值定义为 **TD 目标 $\bar{q}_t$**。
3.  **迭代更新**：有了当前估计值 $q_t(s_t, a_t)$ 和一个基于新信息的目标值 $\bar{q}_t$，一个自然的迭代更新方式是朝着目标值移动一小步。这引出了通用的更新规则：
    $q_{t+1}(s_t, a_t) \leftarrow q_t(s_t, a_t) + \alpha_t(s_t, a_t) [\bar{q}_t - q_t(s_t, a_t)]$
    其中：
    *   $\alpha_t$ 是学习率，控制更新步长。
    *   $[\bar{q}_t - q_t(s_t, a_t)]$ 被定义为**时序差分误差 (TD Error)**。它代表了我们的**估计**与基于**单次采样**的**目标**之间的差距。算法的本质就是不断减小这个采样误差。

将该式进行简单的代数变换，即得到第一张PPT中的统一表达式：
$q_{t+1}(s_t, a_t) = q_t(s_t, a_t) - \alpha_t(s_t, a_t)[q_t(s_t, a_t) - \bar{q}_t]$

至此，我们已经从求解不动点方程的需求，推导出了一个统一的、基于采样的迭代更新框架。

#### **3. TD目标 $\bar{q}_t$ 的不同构造**

所有算法的差异，都归结于它们如何根据各自所求解的贝尔曼方程，利用环境样本来构造TD目标 $\bar{q}_t$。下面我们将逐一进行形式化分析。

*   **Sarsa**
    *   **目标方程 (BE)**: $q_\pi(s, a) = \mathbb{E}[R_{t+1} + \gamma q_\pi(S_{t+1}, A_{t+1}) | \dots]$
    *   **$\bar{q}_t$ 构造**:
        1.  对方程中的随机变量 $R_{t+1}, S_{t+1}, A_{t+1}$ 进行采样。
        2.  在 $(s_t, a_t)$ 之后，我们观测到具体样本 $r_{t+1}$ 和 $s_{t+1}$。
        3.  我们根据当前策略 $\pi$ 选择并执行了动作 $a_{t+1}$，这是对 $A_{t+1}$ 的一次采样。
        4.  用当前值函数 $q_t$ 来估计理论上的 $q_\pi$，即用 $q_t(s_{t+1}, a_{t+1})$ 作为 $q_\pi(S_{t+1}, A_{t+1})$ 的估计。
        5.  组合起来，得到BE右侧期望的单样本无偏（或渐进无偏）估计：
            $\bar{q}_t = r_{t+1} + \gamma q_t(s_{t+1}, a_{t+1})$

*   **Q-Learning**
    *   **目标方程 (BOE)**: $q_*(s, a) = \mathbb{E}[R_{t+1} + \gamma \max_{a'} q_*(S_{t+1}, a') | \dots]$
    *   **$\bar{q}_t$ 构造**:
        1.  对方程中的随机变量 $R_{t+1}, S_{t+1}$ 进行采样，得到 $r_{t+1}, s_{t+1}$。
        2.  项 $\max_{a'} q_*(S_{t+1}, a')$ 不依赖于当前遵循的策略。我们可以直接使用当前的 $q_t$ 来估计它。
        3.  因此，BOE右侧期望的单样本估计为：
            $\bar{q}_t = r_{t+1} + \gamma \max_{a'} q_t(s_{t+1}, a')$

*   **n-step Sarsa**
    *   **目标方程 (n-step BE)**: $q_\pi(s, a) = \mathbb{E}[R_{t+1} + \gamma R_{t+2} + \dots + \gamma^{n-1}R_{t+n} + \gamma^n q_\pi(S_{t+n}, A_{t+n}) | \dots]$
    *   **$\bar{q}_t$ 构造**:
        1.  这是对贝尔曼方程进行 $n$ 次展开后得到的形式。
        2.  我们通过与环境交互，收集一个 $n$ 步的轨迹片段：$(r_{t+1}, s_{t+1}, a_{t+1}), \dots, (r_{t+n}, s_{t+n}, a_{t+n})$。
        3.  用 $n$ 步的累积折扣奖励 $r_{t+1} + \gamma r_{t+2} + \dots + \gamma^{n-1}r_{t+n}$ 替换期望中的奖励部分。
        4.  在第 $n$ 步之后，用 $q_t(s_{t+n}, a_{t+n})$ 来进行自举 (bootstrap)。
        5.  得到TD目标：
            $\bar{q}_t = r_{t+1} + \gamma r_{t+2} + \dots + \gamma^{n-1}r_{t+n} + \gamma^n q_t(s_{t+n}, a_{t+n})$

*   **Expected Sarsa**
    *   **目标方程 (BE, 略微变形)**:
        $q_\pi(s, a) = \mathbb{E}_{S_{t+1}, R_{t+1}}[R_{t+1} + \gamma \mathbb{E}_{A_{t+1} \sim \pi}[q_\pi(S_{t+1}, A_{t+1})] | \dots]$
    *   **$\bar{q}_t$ 构造**:
        1.  我们对 $R_{t+1}, S_{t+1}$ 进行采样，得到 $r_{t+1}, s_{t+1}$。
        2.  对于内部的期望 $\mathbb{E}_{A_{t+1} \sim \pi}[\cdot]$，由于我们知道策略 $\pi$，我们可以**直接计算**这个期望，而无需采样 $A_{t+1}$。
        3.  这个期望的计算结果是 $\sum_a \pi(a|s_{t+1}) q_t(s_{t+1}, a)$。
        4.  组合得到TD目标，它混合了采样（对环境）和精确计算（对策略）：
            $\bar{q}_t = r_{t+1} + \gamma \sum_a \pi(a|s_{t+1})q_t(s_{t+1}, a)$

*   **Monte Carlo (MC)**
    *   **目标方程 (价值函数的定义)**: $q_\pi(s, a) = \mathbb{E}[G_t | S_t = s, A_t = a]$，其中 $G_t = \sum_{k=0}^{\infty} \gamma^k R_{t+k+1}$ 是完整的回报。
    *   **$\bar{q}_t$ 构造**:
        1.  MC方法不使用自举。它等待一个完整的episode结束。
        2.  在时刻 $t$ 之后，观测到的完整回报 $G_t = r_{t+1} + \gamma r_{t+2} + \dots + \gamma^{T-t-1}r_T$ (T为终止时刻) 是对 $\mathbb{E}[G_t]$ 的一次完整采样。
        3.  因此，其TD目标就是这个采样回报：
            $\bar{q}_t = G_t$
    *   **关于 $\alpha_t = 1$**: 当 $\alpha_t = 1$ 时，更新公式变为 $q_{t+1}(s_t, a_t) = \bar{q}_t = G_t$。这对应于一种非增量的MC方法，即直接用（首次）观测到的回报作为价值估计。在更常见的增量实现中，$\alpha_t$ 通常是 $1/N(s_t, a_t)$（访问次数的倒数），这使得 $q_{t+1}$ 成为所有观测到的 $G_t$ 的算术平均值，依然符合我们的统一更新框架。
